# 道旗设计图集 · 2026 年六省区民族文化嘉年华

中国桂花城「同心筑梦 南北共融」道旗设计图共 **14 款**，本仓库为其在线浏览页。

## 浏览地址

https://chenzhuanxin.github.io/daobanner-gallery/

## 交互说明

| 操作 | 说明 |
| --- | --- |
| 左右滑动 / 拖动 | 切换设计方案（触屏、鼠标拖动均支持） |
| ← → 方向键 | 上一款 / 下一款 |
| 鼠标滚轮 | 逐款切换 |
| 点击卡片 | 打开大图（可用方向键或两侧按钮翻页，Esc 关闭） |
| 底部缩略图 | 一键跳到任意一款 |
